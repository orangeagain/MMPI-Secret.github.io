# MMPI-CHN

## MMPI积计分显示

这个项目的目的仅仅是为了查看MMPI背后的记分规则.
 - MMPI计分有庞大的矩阵运算,关联性非常多,所以这个项目可以让你看到背后到底是怎么计算的.
 - 至于结果,这个分支并没有更新常模和现在的数据,所以不具有参考性,想看准确结果的请去原项目.

## 怎么看mf分?

判断女性化和男性化的方式:无法直接判断,因为结果是跟社会平均值相比的,还有一个前提就是你初始性别的选择.mf分是一个绝对值有偏向男或女,但出结果会根据你选的初始性别和社会平均分比较,所以还蛮麻烦的.所以这个项目只能让你看到选项会怎么影响分值,而不会让你准确的计算出结论.
