# MMPI-CHN.github.io

## MMPI积计分显示

这个项目的目的仅仅是为了查看MMPI背后的记分规则.
 - MMPI计分有庞大的矩阵运算,关联性非常多,所以这个项目可以让你看到背后到底是怎么计算的.
 - 至于结果,这个分支并没有更新常模和现在的数据,所以不具有参考性,想看准确结果的请去原项目.

## 怎么看mf分?

判断女性化和男性化的方式:无法直接判断,因为结果是跟社会平均值相比的,还有一个前提就是你初始性别的选择.mf分是一个绝对值有偏向男或女,但出结果会根据你选的初始性别和社会平均分比较,所以还蛮麻烦的.所以这个项目只能让你看到选项会怎么影响分值,而不会让你准确的计算出结论.


## 本地结果存储

项目使用零依赖的 Node 本地服务器。启动方式：

```powershell
npm start
```

浏览器访问 `http://127.0.0.1:8765/MMPI-1-test.html`。如需改端口，可在启动前设置任务专用环境变量 `MMPI_PORT`。

每次点击“提交测试并保存”会在 `storage/results/YYYY-MM-DD/` 中生成：

- 一份格式化的 `.json` 文件，保存结构化元数据、全部作答、VRIN/TRIN、各量表原始分、K校正分、T分和关键项目；
- 一份 `.md` 文件，以表格和中文标题组织同次测试结果，便于直接阅读。

结果目录已加入 `.gitignore`，防止心理测评数据被误提交到公开仓库。保存只发生在 `127.0.0.1` 本地服务中，不会上传到外部网站。

## 在线使用（GitHub Pages）

页面本身是纯静态的，可以直接部署到 GitHub Pages：仓库 Settings → Pages → Deploy from a branch → `main` / `(root)`。

在线版没有后端，计分完全在浏览器中进行，作答数据不会上传。提交后页面会给出“下载 Markdown 报告 / 下载 JSON 数据”两个按钮，内容与本地服务器保存的文件格式一致（由 `origin_js/result_report.js` 统一生成）。只有通过 `127.0.0.1` / `localhost` 访问时才会调用本地服务器的保存接口。
